# Telegram Channel Post Auto Forward to Another Channel Bot

```
git clone https://github.com/BidyutRoy2/tgpost.git && cd tgpost
```
```
npm install
```
Start Bot
```
npm start
```
To Stop
```
CRTL+C
```

- tgpost/
- ├── index.js
- ├── package.json
- ├── .env
